VisiOnRoute is a fleet safety platform that turns vehicle telemetry into clear and reviewable safety insights. It helps fleet teams monitor vehicles, drivers, trips, risky driving events, road risk and coaching activity from one place.

### Features:
- Fleet, vehicle and driver management
- Trip tracking and live operations
- Harsh braking, harsh acceleration, harsh cornering and speeding detection
- Explainable safety events with measured values and rule details
- Driver risk scoring
- Road-risk and geofence maps
- Safety event review and coaching workflows
- Analytics and reporting
- Email verification, role-based access and tenant isolation
- Synthetic data generation for testing and demonstration


##### Technologies used: Python, FastAPI, PostgreSQL, PostGIS, Redis, Next.js, React, TypeScript, Tailwind CSS, MapLibre, Docker, GitHub Actions

Lastly, this is a working hobby project for learning with a live frontend, backend API, database, authentication, email verification, telemetry ingestion and automated deployment. The system uses synthetic data for testing and demonstration purposes
